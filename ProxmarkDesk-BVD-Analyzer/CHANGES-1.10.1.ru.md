# ProxmarkDesk BVD 1.10.1 — Context Actions

## Изменено
- Ручная командная строка Iceman находится в `Инструменты → Консоль Iceman`.
- Удалены входы в старую универсальную форму чтения/дампа из Карты, Ключей и результатов PWD_AUTH.
- Карта теперь ведёт только в контекстные `Действия для этой карты`.
- `OperationPage` строит меню через `ActionRegistry.forCardMenu(CardCapability)`.
- В меню живой карты не показываются действия эмуляции, требующие заранее выбранного дампа.
- Для Ultralight/NTAG парольные действия показываются только для NTAG/EV1 или подтверждённого PWD-типа.
- NDEF-действия скрываются только когда отсутствие NDEF подтверждено; UNKNOWN не трактуется как UNSUPPORTED.
- Добавлены безопасные действия информации для DESFire, ISO14443-B, FeliCa, iCLASS/PicoPass, LEGIC, Topaz, EM410x, HID и T55xx.
- Улучшено определение subtype для Ultralight C/EV1, NTAG и DESFire EV1/EV2/EV3.
- Во время операции показываются текущая команда и прошедшее время.
- Тайм-аут команды больше не завершает PM3-клиент автоматически. Новые команды блокируются до возврата маркера синхронизации или явного `Остановить сеанс`.
- Мягкая кнопка Stop не возвращалась.

## Логика
`TagInfo → CapabilityEngine → CardCapability → ActionRegistry → OperationPage`.
Полный каталог, Lua/Python, ручная консоль и диагностика остаются в `Инструменты`.
