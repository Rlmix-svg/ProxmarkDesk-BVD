# ProxmarkDesk BVD 1.10 — исправление цветов и удаление мягкого Stop

Дата: 16.09.2026

## Цвета

- Базовая тема приложения переключена с `Theme.Material.Light.NoActionBar` на тёмную `Theme.Material.NoActionBar`.
- Для `EditText` добавлены единые цвета основного текста, подсказки и линии ввода.
- Для `CheckBox` добавлены единые цвета обычного, отключённого и отмеченного состояний.
- Для `Spinner` и строк `ListView` используется тёмный адаптер с явным цветом текста и фона.
- Прямое создание нестилизованных `EditText`/`CheckBox` в UI заменено общими helper-методами.

Палитра:
- фон: `#08141F`;
- поверхность: `#0C1C2B`;
- основной текст: `#E1ECF3`;
- вторичный текст: `#96AEBC`;
- отключённый текст: `#718895`;
- акцент: `#00C8AA`.

## Stop

Мягкая кнопка Stop удалена из пользовательского интерфейса:
- экран «Операции»;
- экран чтения;
- каталог/служебные экраны;
- консоль;
- Sniff;
- экран эмуляции.

Команды выполняются до штатного завершения. Для аварийного прерывания остаётся «Остановить сеанс» на экране устройства либо аппаратная кнопка Proxmark3, когда она применима.

Внутренняя реализация `ClientService.stopCommand()` пока сохранена, но UI её больше не вызывает — это оставляет возможность вернуться к корректной мягкой отмене отдельным этапом.
