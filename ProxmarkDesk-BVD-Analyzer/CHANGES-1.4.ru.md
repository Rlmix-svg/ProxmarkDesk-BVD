# ProxmarkDesk BVD 1.4 — функциональное обновление

Графический редизайн отложен. Android ARM64, пакет org.proxmarkdesk.android, versionCode 14. APK подписан прежним локальным сертификатом.

## Изменения

- Во вкладке чтения сначала доступны Авто, Поиск HF, Поиск LF. После определения метки появляются сведения, каталог команд её семейства и доступ к формам чтения, дампа и известных ключей. Для остальных протоколов есть ручной выбор семейства из каталога.
- Справочник: русские описания действий, исходные пояснения Iceman, поиск по мере ввода, фильтр назначения, избранное, справка и редактирование параметров. Встроенный справочный каталог содержит 914 команд. Кнопка обновления получает каталог именно встроенного клиента Android; набор зависит от сборки. Наличие команды семейства не доказывает поддержку всех её функций конкретным чипом.
- Отдельный кэш каждого запроса постоянному клиенту, включая внутренние шаги автоматического опроса и sniff. Вывод записывается по мере поступления; после команды синхронизируется с накопителем. Незавершённые записи распознаются при следующем запуске. При физическом обрыве USB карточка остаётся как историческая, а явная остановка очищает текущий экран.
- Поиск кэша по команде, UID, устройству, русскому назначению и тексту результата. Полный журнал экспортируется отдельно от ограниченного предпросмотра. Старые журналы операций сохраняются во внутренней библиотеке и входят в резервную копию.
- Профили устройств с отдельными библиотеками. Для текущей установки сохранена прежняя библиотека Proxmark3-Easy.
- Выбор внешней папки через системный диалог Android. Приложение создаёт ProxmarkDesk/<профиль>/Дампы, Трассы, Сигналы, Профили, Пароли, Журналы, Отчёты, Сценарии, Резервные копии. Оригиналы остаются во внутреннем хранилище; при отказе доступа отображается ошибка и доступен повтор копирования. Вложенные пути оригиналов сохраняются.
- История паролей разделена по профилям и сохраняется в библиотеке. Копирование папки паролей наружу включается отдельно. Журналы и полная резервная копия тоже могут содержать ключи, введённые в командах.
- Экспорт полной библиотеки в ZIP через системный диалог, без загрузки всего архива в оперативную память.
- Просмотр сохранённых трасс с выбором одного из 21 декодеров trace list. Используется загруженный буфер (-1), а не новая трасса устройства. Для просмотра нужен запущенный офлайн-клиент либо USB-сеанс.
- Вкладка сигналов: получение LF-выборки, сохранение, настройки, декодирование и доступ к инструментам data.
- Сценарии: сохранение последовательностей, выполнение до 100 команд с ожиданием завершения каждого шага, остановка по предупреждению/ошибке или продолжение по выбору пользователя, доступ к Lua. Тайм-аут шага 300 секунд; после транспортной ошибки автоматического повтора нет.
- Консоль обновляется добавлением нового вывода; команды сохраняют зелёное выделение. Черновик строки ввода сохраняется при переключении вкладок и очищается после выполнения соответствующей команды.
- Исправлено распознавание UID в BIN Ultralight с 56-байтным заголовком: число страниц читается из поля pages на смещении 11.

## Как начать

1. Установите APK как обновление существующего приложения.
2. На вкладке Устройство выберите доступную папку внутри Загрузок. Системный диалог Android может не разрешать выбрать сам корень Downloads; создайте или выберите вложенную папку.
3. На вкладке Команды нажмите «Обновить каталог из клиента». Это можно сделать без устройства.
4. Выполните поиск метки. История новых запросов находится во вкладке Журнал.

## Проверка и ограничения

Проверены компиляция Java/DEX, подпись APK, выравнивание 16 КиБ, тесты каталога/кэша, дампов, определения семейств, логики UI, подключения и последовательности авто-sniff. Физическая проверка этого APK на телефоне и Proxmark3 не выполнялась; SAF, жизненный цикл Android и аппаратные команды требуют проверки на устройстве.

Автоопределение остаётся ограничено ответами клиента: неизвестный или неоднозначный формат требует ручного выбора. Приложение не добавляет аппаратных возможностей сверх имеющихся у Proxmark3 Easy. Python, Qt и native Bluetooth в нативной сборке отсутствуют. Исходники приложения используют прежний нативный Iceman v4.21611 и его ранее поставленные изменения; этот архив исходников приложения не заменяет полный архив нативного клиента.
