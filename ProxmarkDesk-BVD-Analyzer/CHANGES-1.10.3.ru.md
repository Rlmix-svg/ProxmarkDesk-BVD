# ProxmarkDesk BVD 1.10.3 — Pipe Fix

- Исправлено ложное `aborted via keyboard!` у длительных команд Iceman, включая `hf mf fchk`.
- В Android-встраивании `kbd_enter_pressed()` больше не читает stdin, если stdin является pipe, а не TTY.
- Служебный `PMDESK_END_...`, поставленный после команды, больше не воспринимается как клавиатурное прерывание и не уничтожается.
- Логика словарей и контекстных действий из 1.10.2 сохранена без изменений.
