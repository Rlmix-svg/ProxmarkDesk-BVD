ProxmarkDesk BVD 1.3 — Авто sniff

Вкладка Sniff: длительность 1–3600 секунд (по умолчанию 30), пауза 1–10 секунд (по умолчанию 1).
Порядок: hf 14a sniff → длительность захвата → hw break → пауза → trace list -t 14a → пауза → trace list -1 -t 14a -c --frame → пауза → trace save -f dumps/sniff.<номер>.
Каждая следующая команда ожидает служебный маркер завершения предыдущей, затем паузу. После sniff ожидание равно заданной длительности захвата.
Встроенный Iceman v4.21611 не имеет команды trace parse. Вместо неё выполняется подробное отображение CRC и задержек кадров из уже полученного буфера.
Номер файла — время запуска в миллисекундах; %d подставляется приложением, а не передаётся Iceman буквально.
Файл sniff.<номер>.trace появляется во вкладке Дампы. Полный вывод просмотра и подробного разбора сохраняется в журнале операции.
Остановить сеанс отменяет дальнейшие команды; если устройство продолжает RF-операцию, нажмите его физическую кнопку. Остановка всего сеанса не сохраняет незавершённый захват.

Проверено: Java/API36, D8, подпись v3, выравнивание APK 16 КиБ, 7 BVD-проверок и тесты последовательности/таймера/пауз/некорректного времени/отмены авто sniff.
Не проверено: реальный захват и остановка по таймеру на Android с Proxmark3.
Пакет и сертификат прежние: устанавливается как обновление BVD 1.2 / ProxmarkDesk 0.7.
