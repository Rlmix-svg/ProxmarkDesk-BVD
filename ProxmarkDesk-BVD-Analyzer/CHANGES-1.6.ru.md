# ProxmarkDesk Android 1.6 — чтение и Lua

Дата сборки: 10 сентября 2026 года. Пакет org.proxmarkdesk.android, versionCode 16. Клиент Iceman v4.21611; Android ARM64, минимальная версия Android 11.

## Изменения

- На вкладке «Чтение» до обнаружения метки — три кнопки: «Авто», «Поиск HF», «Поиск LF». После поиска — карточка и команды/Lua для определённого семейства. Сведения из истории помечены как неподтверждённые сейчас.
- Подбор не закреплён за UID. Неоднозначный результат требует уточнения семейства. Для специальных моделей есть отдельный переключатель: обычная Ultralight не считается UL-5, а строка Ultralight/C/NTAG Compatible не подтверждает конкретную NTAG.
- Общий каталог: команды, Lua и включённые Python-инструменты; русские описания, поиск по мере ввода, фильтр по типу и избранное. Карточка действия показывает параметры/справку, зависимости и ограничения. Совпадение семейства не гарантирует поддержку каждой команды конкретной моделью метки.
- Привычные формы чтения/сохранения дампа доступны из карточки метки. Отдельная вкладка «Сценарии» убрана из навигации; сохранённые последовательности доступны через «Команды». Вкладка Python сохранена.
- Исправлена косвенная зависимость hf_mf_autopwn.lua → commands.lua → pm3_cmd.lua. Генератор ресурсов создаёт pm3_cmd.lua из заголовка клиента и mfc_default_keys.lua из его словаря. Добавлен адаптер bit к встроенному bit32 для trace_parse.
- 22 библиотеки Lua, 80 исходных Lua-скриптов (включая тестовые) и диагностический pmdesk_envcheck.lua. Полный набор ресурсов — 532 файла из одной версии Iceman.
- Ресурсы проверяются по SHA-256 при старте службы и перед подключением. Старый data-v1.ready больше не мешает восстановлению. Отсутствующие файлы восстанавливаются; изменённые штатные файлы перед заменой копируются в library/backups/resources. Дополнительные пользовательские файлы сохраняются.
- «Команды → Lua: диагностика и библиотеки»: проверка/восстановление, список библиотек, просмотр исходников, безопасная проверка загрузки библиотек и компиляции Lua без выполнения скриптов на метке. Отчёт проверки можно найти в журнале и библиотеке.

## Проверка на компьютере

- Сборка Java/DEX, подпись APK и выравнивание 16 КБ.
- Тесты каталогов, распознавания меток, кеша, работы с файлами, последовательности Auto Sniff, Python bridge и Python-инструментов.
- Новые тесты: первоначальная установка, восстановление недостающей библиотеки, резервная копия изменённой, сохранение пользовательского скрипта, повторная установка без лишней перезаписи, запрет выхода за папку ресурсов, подбор MFU без чужих Classic/специальных скриптов.
- Реальный Windows-клиент Iceman v4.21611 в офлайн-режиме загрузил 22 библиотеки из упакованного набора: Missing modules 0, Syntax errors 0, Lua environment OK. Скрипты компилировались, их операции на метках не выполнялись.

## Что требует проверки на телефоне

Эта сборка не запускалась на физическом Android в текущей сессии. Требуются проверка обновления поверх 1.5 с сохранением данных, OTG/root, поиска разных LF/HF-меток, прокрутки и ввода на новом экране, чтения/дампов/sniff/эмуляции с устройством. Успешная загрузка библиотек не означает, что все Lua-скрипты проверены на метках. Скрипты с внешними программами или требованиями RDV4 помечены отдельно; наличие Python не делает любые desktop-зависимости доступными.

## Установка и сборка

APK подписан прежним сертификатом разработки, package id сохранён: устанавливайте как обновление. При конфликте подписи не удаляйте рабочую версию с данными — сначала экспортируйте библиотеку и сообщите текст ошибки.

Для самостоятельной сборки используйте build.py и исходники Iceman v4.21611 с Android-изменениями, описанными в README.md. prepare-resources.py является обязательной частью сборки. Python-окружение и собственные адаптеры включены в исходный пакет. Самостоятельная сборка создаёт свой сертификат и не заменит установленный APK с другим сертификатом.

Графическое оформление в этой версии специально не перерабатывалось.
